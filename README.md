# Komari Glass Kv

Kv 定制的 Komari 毛玻璃监控主题，基于
[Komari Glassmorphism](https://github.com/sanrokamlan-prog/komari-theme-Glassmorphism)
v3.3.3 二次开发。

![预览](docs/preview.png)

## 下载与安装

下载 [Komari-Glass-Kv-3.3.3-kv.8.zip](./Komari-Glass-Kv-3.3.3-kv.8.zip)，
进入 Komari 后台的主题管理页面，直接导入 ZIP。

主题信息：

- 名称：Komari Glass Kv
- 版本：3.3.3-kv.8
- 作者：Kv
- 默认卡片密度：compact
- 支持浅色、深色及北京时间自动模式

## Kv 定制内容

- 节点卡片改为纵向信息面板，服务商、系统、硬件、费用和期限按行展示
- 服务商优先显示后台手动分组；IP/ASN 归属仅保留在悬浮说明中，带宽和三网标签不会干扰识别
- CPU、内存、Swap、硬盘和流量使用独立彩色进度轨道
- 增加实时上传/下载与累计上传/下载
- 系统资料统一显示服务商、硬件与配额、CPU 型号、操作系统、费用和期限；不再显示内核版本
- 已设置的金额与付费周期使用独立的绿色、金色信息标签展示
- 价格、周期、服务商、运行和到期信息直接归属系统资料，不再依赖旧身份区块
- 剩余时间不足 10 天或已过期时显示红色警示
- 增加电信、联通、移动线路名、延迟、丢包与明确标注的五级线路质量短柱
- 保留原版聚合延迟与丢包离散短柱
- 保留费用、收藏、搜索、详情图表、地图和高级工具
- 保留 Komari 原有后台、终端和管理页面

## 后台显示设置

`kv.6` 开始，前台展示层使用 Komari 的托管主题设置，不修改 Komari 核心数据结构：

- 服务器卡片可选择完整、紧凑、监控、极简或自定义方案
- 身份与系统字段合并显示为紧凑的系统资料块；使用情况、网络流量和网络质量保持独立区块
- 每个区块的服务商、系统、国旗、带宽、费用、期限、硬件、Swap、流量和三网质量等字段可单独控制
- 收藏、详情入口、自定义标签和离线遮罩可单独开关
- 列表视图的列可控制显示和顺序
- 顶部导航、页脚、首页搜索及卡片/列表切换可单独开关
- 原有总览卡片、快捷控制、详情指标、详情图表、背景、隐私和高级工具设置继续保留

修改入口：Komari 后台 → 主题管理 → 当前主题设置。节点名称和在线状态属于必要身份信息，固定保留，避免卡片失去可识别性。

三网识别依赖 Ping 任务名称包含“电信、联通、移动”或相应英文关键词。
未配置对应任务时，该线路显示 `-`。

Komari 暂无独立的带宽和三网线路类型字段，可在节点标签中配置：

```text
带宽:1000G;电信:CN2/CN2;联通:CMI/CMI;移动:4837/4837
```

这些结构化标签会进入卡片对应位置，不会再作为普通标签重复显示，也不会参与服务商自动识别。三网五格短柱明确标注为“质量”，按延迟和丢包中较差的等级计算，不代表网速；丢包数值也会按风险显示颜色。底部综合短柱仍来自真实历史记录。

## 开发与构建

要求 Bun 1.2 或更高版本：

```bash
bun install
bun run lint
bun run build
```
